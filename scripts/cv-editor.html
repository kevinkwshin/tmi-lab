TMI-LAB / CV

연구 기록을 한 번 입력하세요.

논문·학회발표·과제를 저장하면 같은 기록으로 홈페이지와 CV를 만듭니다. 논문은 DOI로 전체 저자와 출판 정보를 불러오고, 본인 기여는 확인한 내용만 직접 표시합니다.

공개할 정보만 입력하세요. 저장한 기록은 공개 GitHub 저장소와 홈페이지·CV에 반영됩니다. 개인 연락처와 비공개 연구비는 입력하지 마세요. 저장 후 사이트에 반영하려면 변경 파일을 GitHub에 올려야 합니다.

기록을 불러오는 중입니다.

논문 추가

본인의 논문이 맞는지 제목·저자 순서·학술지를 확인한 뒤 저장하세요.

영문 CV용 표기 (한글 등 비라틴 원문은 필수)

출판사가 제공한 공식 영어 표기가 있으면 그대로 입력하세요. 원본 서지정보는 보존하며 영어 CV/PDF에만 이 표기를 사용합니다.

본인 기여 공식 논문에 명시된 경우에만 선택하세요. 저자 순서에서 자동 추정하지 않습니다.

직접 추가한 논문

자동 발견·기존 선정 논문과 DOI로 합쳐집니다. 여기서는 직접 추가한 기록을 수정·삭제합니다.

    학회발표 추가

    영문 CV용 표기 (한글로 입력한 항목은 필수)
    본인 기여 (확인된 경우)
    DOI·학회 프로그램 링크 추가

    저장된 학회발표

      연구과제 추가

      영문 과제 정보 (한글로 입력한 항목은 필수)

      저장된 연구과제

        이 입력 화면은 현재 컴퓨터에서만 실행됩니다. 논문 서지정보는 Crossref에서 조회하며 Google Scholar를 자동 수집하지 않습니다.
        서지정보의 수정·저자 기여·공개 범위는 저장하기 전에 직접 확인하세요.
